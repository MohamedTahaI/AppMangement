# تجهيز ملف التطبيق لأندرويد

## قبل أول بناء

ثبّت أداة البناء على الكمبيوتر:

```bash
npm install --global eas-cli
```

سجّل الدخول إلى حساب Expo:

```bash
eas login
```

من داخل مجلد المشروع `my-app`، أنشئ إعداد المشروع عند الطلب، ثم ابدأ بناء ملف APK:

```bash
eas build -p android --profile preview
```

إذا طلبت الأداة ربط المشروع بحساب Expo، وافق واتبع التعليمات الظاهرة. انتظر حتى تظهر رسالة اكتمال البناء ورابط تنزيل الملف.

## تنزيل التطبيق وإرساله

1. افتح رابط البناء الذي يظهر في الطرفية، أو افتح صفحة المشروع في موقع Expo ثم صفحة البناءات.
2. اضغط **Download** لتنزيل ملف APK إلى الهاتف أو الكمبيوتر.
3. أرسل ملف APK إلى هاتف المدير عبر واتساب كـ **مستند**، أو نزّله مباشرة إلى الهاتف.
4. افتح الملف على الهاتف. إذا منع Android التثبيت، اختر **الإعدادات** ثم فعّل **السماح من هذا المصدر** للتطبيق الذي فتح الملف (مثل واتساب أو المتصفح).
5. ارجع إلى ملف APK واضغط **تثبيت**. بعد اكتمال التثبيت افتح **مدير العمارة**.
6. بعد التثبيت، يمكنك إيقاف خيار السماح بالتثبيت من هذا المصدر من إعدادات Android.

اسم التطبيق ورمزه ورمز الشاشة الأولى إعدادات أولية قابلة للاستبدال لاحقًا. لا تُرسل رمز الاتصال بجدول Google أو نسخة البيانات الاحتياطية عبر مجموعة عامة.
