# مراجعة التصميم — Phase 10C

## التغييرات المشتركة

- توحيد الألوان والخطوط والمسافات والحواف والظلال والحركة في `src/theme/index.ts`، مع خط Cairo.
- توحيد عناصر الأزرار والبطاقات والعناوين والمبالغ والحالات والنماذج والقوائم والحالات الفارغة والتحميل والنوافذ السفلية.
- تطبيق تباين أعلى، RTL، خلفية موحدة وانتقالات محدودة تحترم إعداد تقليل الحركة.
- تحديث شريط التبويب والدرج والترويسة بأيقونات MaterialIcons، وإضافة المساحات الآمنة حول الترويسة والشريط السفلي.
- ضبط البطاقات الرئيسية والإحصائية وصفوف القوائم لتقليل الظلال داخل القوائم، وإبقاء الظل للبطاقات المهمة.

## مراجعة الشاشات

| الشاشة | ما تغيّر |
|---|---|
| الرئيسية | بطاقة إجمالي متدرجة، بطاقتا الإحصاءات، تقدم الشهر، إجراءات سريعة، التحصيلات الخاصة والمتأخرون وآخر العمليات؛ أرقام متحركة وحالات تحميل وخطأ. |
| التحصيل الشهري | عنوان وشهر وملخص موحد، أشرطة تصفية، بطاقات وصفوف واضحة وحالات دفع بأيقونة ونص. |
| تسجيل دفعة | اختيار سنة وشهور أو أكثر، حالات الشهور، مبلغ وحقول أكبر ورسائل نتيجة واضحة. |
| اختيار شقة | بحث واضح، صفوف كبيرة، skeleton وحالة فارغة. |
| حساب الشقة | ملخص الشقة، شبكة الشهور، التحصيلات الخاصة وسجل الدفعات ضمن بطاقات موحدة. |
| المصروفات | إجمالي الشهر، قائمة المصروفات الثابتة، المرشحات، ونموذج المصروف في نافذة سفلية. |
| التحصيلات الخاصة | بطاقات تقدم، مرشحات، نموذج إنشاء سفلي وحالات واضحة. |
| تفاصيل التحصيل الخاص | تقدم ومبالغ وحالات لكل شقة، تصفية، ونوافذ دفع وتعديل وتأكيد. |
| المتأخرون | اختيار شهري/خاص، مرشح الشهر أو التحصيل، صفوف رصيد وحالات وأزرار دفع. |
| الشقق | قائمة قابلة للبحث، دخول متدرج لأول عشرة صفوف، نموذج سفلي، وتأكيد الإيقاف ورسالة نجاح. |
| قيمة الاشتراك | بطاقة السعر الحالي، اختيار الشهر، نموذج سفلي وتأكيد عند استبدال سعر موجود. |
| بيانات العمارة | حقول مبسطة للشهر والاسم مع تأكيد ونجاح. |
| أنواع المصروفات | صفوف موحدة وأزرار الإضافة/التعديل/الإخفاء. |
| تسوية المبلغ الكلي | فصل إجمالي الدفعات وصافي التسويات ومعاينة الرقم، خيارات زيادة/نقص وتأكيد السبب والإلغاء. |
| كشف الشهر | بطاقات الإجماليات وأقسام الدفعات والمصروفات والتحصيلات الخاصة. |
| سجل العمليات | شريط المرشحات وصفوف موحدة بحسب نوع العملية. |
| التصدير والنسخ الاحتياطي | اختيار الفترة وأزرار واضحة للتصدير والحفظ والاستعادة ورسائل النتيجة. |
| الجدول الأونلاين | مؤشر حالة ملون، حقول الاتصال وأزرار الاختبار والتحديث وإعادة البناء المؤكدة. |
| رقم سري | حقول إدخال واضحة وحالة مفعّل/غير مفعّل وتأكيدات عربية. |
| صفحة اختبار الواجهة | عرض عناصر النظام واختبار حالات الحركة والقائمة ذات 50 عنصراً؛ محمية في نسخ الإنتاج. |
| صفحة الاختبار الذاتي | تشغيل اختبارات قاعدة البيانات والتحصيل؛ محمية في نسخ الإنتاج. |

## ما يحتاج تحققاً بصرياً على الجهاز

المراجعة هنا من الكود والثيم وليست فحص لقطات على هاتف Android. يلزم التأكد يدوياً من قصّ النصوص العربية، تناسب التدرج والأحجام مع أبعاد الهاتف، سحب الدرج من الحافة اليسرى، عدم ظهور ومضة بيضاء أو تداخل مع أزرار النظام، وسلاسة قائمة 100 شقة مع «إزالة الرسوم المتحركة» مفعّلة.
