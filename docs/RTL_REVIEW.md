# مراجعة اتساق RTL

تمت المراجعة على مسارات التطبيق داخل `src/app/` ومكونات الواجهة في `src/components/`.
وحّدت النصوص في `AppText` باتجاه كتابة عربي افتراضي وانكماش مرن، وربطت العناوين
وملخصاتها بـ `SectionHeader`. أزيلت محاذاة النص الثابتة لليمين/اليسار، واستبدلت
المواضع والحواف الفيزيائية بخصائص `start` و`end` المنطقية. لم تتغير الألوان أو
منطق البيانات.

| الشاشة | ما تم ضبطه |
|---|---|
| الرئيسية | عنوان الشاشة وعناوين الأقسام وصفوف «عرض الكل» تستخدم `SectionHeader`، والنصوص تستخدم `AppText`. |
| التحصيل الشهري | العنوان والبحث والحقول وحالات الشقق تستعمل اتجاه RTL الافتراضي. |
| التحصيلات الخاصة | عناوين القائمة والتفاصيل والنصوص تستخدم المكونات المشتركة. |
| تفاصيل التحصيل الخاص | عناوين الأقسام وصفوف الشقق والمصروفات أصبحت RTL وقابلة للانكماش. |
| المصروفات | عنوانا المصروفات الثابتة والأخرى يستخدمان `SectionHeader`؛ زر «إضافة مصروف» مقيد بعرض 45% ويلتف نصه بدلاً من الخروج عن الشاشة. |
| إضافة/تعديل مصروف | تسميات الحقول وخياراتها تستخدم `AppText`، وحقل البحث/النص يعتمد اتجاه RTL من المكون المشترك. |
| أنواع المصروفات | عنوان الشاشة ونصوص الصفوف والأزرار RTL. |
| الشقق | العنوان والبحث وصفوف الشقق وأزرارها تستخدم النصوص المرنة RTL. |
| حساب الشقة | العنوان وملخص الأشهر وسجل الدفعات RTL. |
| كشف الشهر | عنوان الكشف وعناوين الأقسام وصفوف التقرير RTL. |
| سجل العمليات | العنوان والبحث والفلاتر والصفوف RTL؛ لا توجد محاذاة نص ثابتة لليسار أو اليمين. |
| تعديل الرصيد | عناوين الشاشة والأقسام وتسميات الحقول وسجل التعديلات RTL. |
| التصدير والنسخة الاحتياطية | العناوين وأقسام التقرير والنسخة الاحتياطية RTL. |
| الجدول الأونلاين | العنوان والحقول وحالات المزامنة RTL. |
| بيانات العمارة | العنوان وتسميات الحقول RTL. |
| رقم الدخول | العنوان والرسائل والحقول RTL؛ عناصر الرقم تبقى مرنة داخل العرض. |
| المتأخرون | عنوانا الشاشة والقسم وخيارات التحصيل ونتائج القوائم RTL. |
| تسجيل دفعة واختيار الشقة | العناوين، الأشهر، تفاصيل الدفع، والحقول RTL. |
| القائمة الجانبية | موضعها وحوافها تستخدم خصائص منطقية؛ ترتيب الرأس والقائمة يعتمد RTL. |
| شريط التبويب والإضافة السريعة | ترتيب التبويبات يعتمد اتجاه RTL، مع بقاء الأيقونات غير الاتجاهية كما هي. |
| الفلاتر ومحدد الشهر والتقدم | شرائح الفلاتر والحقول RTL؛ شريط التقدم يبدأ من `start`، وأزرار الشهر السابق/التالي تبقى متوافقة مع الأسهم. |
| صفحات التطوير | نصوص الاختبار تستخدم `AppText`، ولا تتغير سلوكياتها. |

### تفعيل RTL عند التشغيل

يستدعي `src/app/_layout.tsx` كلّاً من `I18nManager.allowRTL(true)` و
`I18nManager.forceRTL(true)` قبل تصدير مكوّن الجذر. وفي وضع التطوير يسجل
`I18nManager.isRTL` مرة واحدة عند تركيب الجذر.

لم يتوفر جهاز Android في بيئة التعديل، لذلك يلزم إغلاق التطبيق بالكامل وفتحه
مجدداً على الهاتف بعد تغيير اتجاه RTL؛ ثم التأكد من ظهور `I18nManager.isRTL: true`
في سجل التطوير.
